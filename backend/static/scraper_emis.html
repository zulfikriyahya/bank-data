Trigger Scraping Data EMIS

Langkah 1: Login ke EMIS di browser, selesaikan captcha sampai dashboard muncul.
Langkah 2: Install extension Cookie-Editor, buka di halaman EMIS, klik Export → pilih JSON, simpan sebagai file.
Langkah 3: Buka DevTools (F12) → Console, jalankan kode ini lalu simpan hasilnya (otomatis ke clipboard) sebagai file:
copy(JSON.stringify(Object.keys(localStorage).map(k => ({name: k, value: localStorage.getItem(k)})), null, 2))
Langkah 4: Upload kedua file di bawah ini.
